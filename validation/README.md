# Strategy Validation

This directory contains selected Python audit scripts developed during the BigHero V8 experimentation process.

The scripts focus on examining specific aspects of the bot's behaviour, including:

- Exploration and route-scoring decisions
- Environmental resource information
- Escape and tactical safety scenarios

These utilities formed part of a broader development workflow involving debugging, replay analysis and repeated strategy refinement.

Some scripts may depend on the original Battlecode environment or additional project files and are not presented as standalone test suites.
